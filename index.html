What each project had to get right.

Every repository below is public. Descriptions lead with the hard part rather than the stack — the stack is on the tags.

latent-atlas

A browser for embedding spaces. Projects 2M product vectors to 2D once, then streams tiles to a WebGL canvas so panning stays smooth instead of re-running UMAP on every zoom.

  • Python
  • PyTorch
  • UMAP
  • WebGL
Repository

driftwatch

Production monitoring that pages a human only when it should. Tracks PSI and KS statistics per feature, and separates genuine distribution shift from the weekly seasonality that used to trigger every false alarm.

  • Python
  • Airflow
  • Evidently
  • Postgres
Repository

arxiv-sift

Ranks each morning's preprints against everything you have already read. Sentence embeddings in FAISS, plus a citation-graph term that surfaces papers your reading history points at but never quite reached.

  • sentence-transformers
  • FAISS
  • FastAPI
Repository

tempo

Genre classification from mel-spectrograms. The interesting part was the augmentation pipeline — pitch shift and time stretch applied on the GPU during training, which moved top-1 accuracy from 79% to 88%.

  • PyTorch
  • librosa
  • CUDA
Repository

feedstock

A streaming feature store with point-in-time correctness, so a feature read at training time returns exactly what it would have returned at inference time. Kafka in, Flink through the middle, Redis out.

  • Scala
  • Kafka
  • Flink
  • Redis
Repository

sweepboard

Ten thousand hyperparameter runs on one screen. Parallel coordinates with brushing on every axis, so you can isolate the region of the search space that actually produced the good checkpoints.

  • TypeScript
  • D3
  • React
  • W&B API
